# Ложечку за бабушку

Учебный однопользовательский 2D-прототип ER-Studio на Construct 3. Бабушка готовит гречку и подаёт её внуку: игрок получает внукокалории, полезность, вредность и монеты.

Готовый чистый архив: [Releases](https://github.com/Gundersk/A-Spoonful-for-Grandma/releases). Первая версия — prerelease-кандидат до ручной проверки в Construct.

## Открыть игру

Клонируйте репозиторий, откройте `game/project.c3proj` как папочный проект в Construct 3 и запустите Preview. Исходная версия редактора — r506.3; используются два слоя и пустой Event Sheet. Для игры Node.js и MCP не нужны. Если доступ к папкам в вашей среде редактора недоступен, создайте `.c3p` по [инструкции](docs/SETUP.md#игра-без-инструментов-разработчика).

Управление: WASD/стрелки — ходьба; E — взаимодействие/подбор; ЛКМ — бросок к курсору, до 220 пикселей; Q — постановка рядом со станцией либо на пол.

Начните у столешницы: взять кастрюлю → набрать 1–10 ложек гречки → помыть у раковины → поставить на плиту → подождать 5 секунд → забрать → подать на стол. Награда зависит от количества гречки. Кастрюля изначально стоит на столешнице, не хранится внутри мебели.

## Состояние прототипа

Одна кухня, одна кастрюля, один рецепт. Есть перенос, состояния содержимого, постановка на поверхности, бросок с высотой полёта, таймер варки, показатели и два режима камеры. В кухне камера фиксирована; следование подготовлено для будущих больших сцен. Книга рецептов и инвентарь пока запланированы.

**Текущая сборка требует ручного открытия и Preview в Construct.** Автоматические проверки не подтверждают визуальное качество и работу редактора. Полный статус и ограничения: [STATUS](docs/STATUS.md), сценарий демонстрации: [TESTING](docs/TESTING.md).

## Проверить и упаковать

Из корня репозитория, Node.js 22+ (проверено на 24):

```powershell
npm run check
npm test
```

Зависимостей npm у самой игры нет; `npm install` в корне не требуется. MCP устанавливается отдельно и только с разрешения: [MCP_SETUP](docs/MCP_SETUP.md).

Чистый пакет для сдачи: `py -3 tools/packaging/package.py --version 0.1.0` (Windows) либо `python3 tools/packaging/package.py --version 0.1.0`. Результат в `dist/`, в Git не хранится. Содержит только `.c3p`, README и контрольные суммы. [Порядок выпуска](docs/RELEASING.md).

История версий — Git и [CHANGELOG](docs/CHANGELOG.md). Репозиторий один; сдаваемые версии отмечаются тегами. [Условия использования материалов](NOTICE.md).

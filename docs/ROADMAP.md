# Ближайший план

## Сейчас

- Ручная приёмка минипрототипа с камерой в Construct r506.3: управление, цикл 1/10 ложек, постановка, бросок, неподвижный HUD.
- После приёмки — релиз для учебного дедлайна. Не называть release candidate проверенным релизом.

## Затем — книга рецептов

Сначала согласовать открытие/закрытие, вид карточки, вывод ингредиентов/этапов и доступность рецептов. Первый объём — информация о уже существующей гречке. Не добавлять новые рецепты ради UI. Желательны отдельные данные рецепта и модуль представления на существующем UI-слое. Точные клавиши/макет ещё не утверждены.

## Затем — инвентарь

Сначала согласовать: что в нём хранится, число слотов, стаки, связь с предметом в руках, как брать/класть и надо ли останавливать игру при открытии. Не считать уже имеющиеся числовые запасы полноценным инвентарём. Сохранять одно логическое состояние каждого предмета; не дублировать кастрюлю в hands и слоте. Первая реализация отдельно от книги рецептов.

## Позже, только после согласования

Отдельные станции вместо впеченной мебели, согласованный набор графики, новые блюда, инструменты/крючки, закупка за монеты, улучшения и автоматизация, события/концовки, внук и трансформации. Большие локации/огород и переходы с follow-камерой. Сохранение игры и полноценная модель нескольких предметов потребуют отдельных решений. Ни один пункт здесь сам по себе не поручение ИИ на реализацию.

# Изменения

## После 0.1.0-rc1 — переноска вниз — 01.11.2026

Codex, ветка fix/grandma-carry-walk-south. Исправлен отсутствующий шаг при переноске вниз: вместо однокадрового carry_walk_S подключена новая carry_walk_S_generated (4 цельных кадра, 8fps, цикл). Исходные кадры/рабочие направления сохранены; склейки частей тела нет. Добавлены регрессии выбора/непрерывности/остановки анимации и переходов. Автоматические проверки и визуальный просмотр кадров выполнены; Preview текущего исправления не подтверждён. Подробности reports/2026-11-01-carry-south.md.


## 0.1.0 — кандидат минипрототипа — 01.11.2026

Подготовил Codex по запросу владельца. Первоначальный импорт текущей рабочей тестовой версии, без новой игровой механики. Включены существующий цикл гречки, перенос/бросок, поверхности и два режима камеры. Кухня остаётся статической.

Добавлены командная документация, актуальные реестры, инструкции ИИ/дизайнера, workflow/Issue/PR-шаблоны, локальный установщик закреплённого исправленного MCP, автоматические проверки и чистая упаковка. Книга рецептов/инвентарь только отмечены в плане. Исходный концепт сохранён отдельно от актуальных решений. Старые повреждённые спрайтовые попытки не представлены как рабочая реализация.

Проверки и ограничения первоначального импорта — reports/2026-11-01-bootstrap.md. Последний Preview пользователем ещё не записан, поэтому 0.1.0 пока кандидат, не подтверждённый релиз.

Каждая дальнейшая игровая правка: новая запись с датой, автором/PR, изменением поведения и проверками; одновременно обновить STATUS и реестры.

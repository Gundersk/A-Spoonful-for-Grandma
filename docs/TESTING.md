# Проверка минипрототипа

## Автоматически

В корне: `npm run check`, `npm test`; при установленном MCP — `npm run mcp:check`. Первый проверяет JSON/ссылки/скрипты/кадры/полигоны/реестры и лимиты. Второй — регрессии логики и камеры с mock API. MCP проверяет структуру собственным валидатором. Ни один из них не запускает Construct.

## Вручную в Construct

Записать версию редактора, commit, исполнителя, дату, открытие и результат каждого сценария. До фактической проверки статус «не проверено». Для небольшого отчёта можно приложить скриншот или видео в Issue.

| Сценарий | Ожидаемый результат | Текущий результат |
|---|---|---|
| Открыть game/ либо упакованный .c3p, Preview | Нет assertion/error; одна бабушка, кухня и HUD | Не проверено для текущего импорта |
| WASD/стрелки в 8 направлениях, упереться в стол/границы | Перемещение, коллизии, непрерывная анимация; нет лишней статичной бабушки | Не проверено |
| Идти вниз с кастрюлей 3–5 секунд, остановиться, снова пойти и поставить предмет | carry_walk_S_generated непрерывно чередует ноги, остановка carry_idle_S, после постановки обычный walk_S | Не проверено в Preview; маршрутизация и метаданные проверены автоматически |
| Идти NW и NE с кастрюлей, переключить направление, остановиться | Один carry_walk_NW_generated зеркалится для NE, ноги чередуются, смена зеркала не сбрасывает фазу; idle и обычная ходьба прежние | Не проверено в Preview; маршрутизация/цикл/зеркало проверяются тестом |
| Пройти кухню | Камера static, полный прежний вид, HUD неподвижен | Не проверено |
| Взять, 1 ложка, мойка, варка 5с, подача | 10 вккал, 1 монета; польза 0.5, вред 0.1 | Не проверено |
| Повторить с 10 ложками | 100 вккал, 10 монет; польза 5, вред 1; 11-я ложка запрещена | Не проверено |
| Помыть 1 ложку, добавить ещё | Добавление разрешено, raw, нужна повторная мойка | Не проверено |
| Постановка на столешницу и обе конфорки | Кастрюля видна на поверхности, банка блокирует занятый участок | Не проверено |
| Подбор у стола с разных доступных сторон | Берётся по близости к кастрюле, издалека нет | Не проверено |
| Бросок в стол/плиту по центру и краю | Ближайшее допустимое положение, без выхода за края; washed на плите начинает варку | Не проверено |
| Стол за спиной, бросок вперёд | Кастрюля не прилипает назад из-за начального перекрытия | Не проверено |
| Близкая/далёкая цель, промах, разное содержимое | Дальность до 220, близкий бросок короткий, промах возвращает содержимое в руки | Не проверено |
| Повторно подать/подобрать после подачи | Нет повторной награды; при взятии кастрюля становится пустой | Не проверено |

Follow не включать в сдаваемой кухне. Его ручной тест — на отдельной копии по CAMERA.md; тест контроллера не означает готовый огород. После приёмки заполнить отдельную запись ниже, сохранив сведения об ограничениях.

## Журнал ручных проверок

Нет записи успешного Preview последней сборки. Шаблон: дата; исполнитель; commit/tag; Construct release; способ открытия; пройденные сценарии; ошибки; ссылка на Issue/снимки. Не заменять эту запись результатом CI.

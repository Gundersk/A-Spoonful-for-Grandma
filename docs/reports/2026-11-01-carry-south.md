# Ходьба вниз с предметом

Дата: 01.11.2026. Исполнитель: Codex по сообщению владельца. Ветка: fix/grandma-carry-walk-south.

## Причина

Grandma.walk_S имеет два кадра, speed6, loop=true. Grandma.carry_walk_S имел один кадр, speed0, loop=false; PNG побайтово совпадает с carry_idle_S (SHA256 начинается с44704a76ddf30e43). player.js корректно выбирал carry_walk_S при движении вниз с предметом и задавал runtime animationSpeed6, но единственный кадр не мог показать шаг. Поэтому это отсутствие спрайтовых фаз и неверная заготовка анимации, а не сброс воспроизведения каждым tick. В коде запуск уже выполнялся только при смене имени.

## Изменение

Built-in imagegen создал новый лист цельных фигур по референсам walk_S000/001 и carry_idle_S000. Отдельная carry_walk_S_generated содержит4 кадра256×320, Origin(.5,.95), speed8, loop=true. Старая carry_walk_S сохранена как архивная, carry_idle_S и обычная walk_S не изменены. Добавление/PNG/Origin выполнены исправленным MCP через SDK, без передачи base64 в контекст модели. PNG читаются и отправляются в коде.

player.js выбирает новый набор только для moving+carrying+S. Без предмета остаётся walk_S, остановка — carry_idle_S. Другие направления сохранены. Не добавлены объекты, UID, слои, события или механики. Изменён только выбор анимации существующей Grandma UID8.

## Просмотр кадров

В sheet.png и frames.png просмотрены все4 фигуры: ведущая левая нога, сближение ног, ведущая правая, переход. Обе руки подняты, предмета в изображении нет. Голова/кисти/обувь целиком внутри полей. После целокадровой нарезки использован один общий масштаб и выравнивание по вершине; части тела не переставлялись и не дорисовывались. Цельная фигура немного отличается от старого idle, как ожидается от новой генерации; её визуальный переход с idle надо подтвердить в игре.

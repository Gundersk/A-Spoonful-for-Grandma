# Подготовка командного репозитория

Дата: 01.11.2026. Исполнитель: Codex по поручению Gundersk. Задача: организовать передачу текущего прототипа и командную работу, без книги рецептов/инвентаря и без изменения игровых правил.

## Состав

Нативная папка game/ скопирована из актуальной тестовой копии после камеры. Включены только файлы проекта; `.bak`, UI-state редактора, images.zip, старые инструкции/LLM-context и локальная `.codex` исключены. Включённые игровые файлы сверены побайтово с источником. Основной, восстановленный и исходный тестовый проекты в этом этапе не изменялись.

Документы: концепция и исходный DOCX с визуальными референсами, архитектура/состояния, статус/план/журнал, актуальные реестры объектов/графики, установка/работа с ИИ и MCP, инструкции дизайнеру, шаблоны задач/PR/handoff. Служебные файлы находятся вне game/. Книга рецептов и инвентарь зафиксированы как следующие обсуждаемые задачи.

## Следующая приёмка

Открыть упакованный кандидат в Construct r506.3, пройти TESTING.md, записать фактический результат и при успехе оформить проверенную версию. До этого пакет не объявлять успешно запускающимся. Текущий репозиторий становится рабочей базой; старую тестовую папку не развивать параллельно. Для дизайнерских предложений доступны Issue/PR-шаблоны, принятие и импорт раздельны.

## Публикация

Исходники отправлены в main. GitHub Actions успешно выполнил Project checks: https://github.com/Gundersk/A-Spoonful-for-Grandma/actions/runs/41316803207 . Отдельный prerelease prototype-0.1.0-rc1 привязан к commit 1935208 и содержит чистый ZIP и .c3p. Issues1–3 фиксируют приёмку, книгу рецептов и инвентарь; новые механики не реализовывались. Репозиторий на момент подготовки публичный, это настройка владельца; локальные секреты/конфигурация не публиковались. CODEOWNERS указывает Gundersk как ревьюера.

Защита main настроена отдельно через GitHub API: PR + 1 approval + CODEOWNERS + обязательный project check; force-push/удаление запрещены. Администратор имеет bypass (enforce_admins=false). Это не абсолютный запрет владельцу обходить правила.

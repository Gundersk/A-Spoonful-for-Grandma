# Источники и состояние графики

Точное соответствие object/animation/frame/PNG и размеры — ASSETS.md (генерируется из реального проекта). Происхождение некоторых прежних кадров установлено только до локальной рабочей копии; не приписывать им неизвестного автора/лицензию.

| Набор | Исходник в репозитории | Использование / ограничения |
|---|---|---|
| Новая бабушка W/SW и перенос | art/sources/grandma/sheet_*.png | Цельные AI-generated листы; из них нарезаны generated-анимации. E/SE те же кадры с зеркалом в player.js. Остальные направления/idle из ранее подготовленного набора, его игровой оригинал сохранён в game/images. |
| Кухня до/после отделения стола | art/sources/kitchen/kitchen_original.png, kitchen_without_table_v2.png | Текущий KitchenMockup без стола; остальные станции пока в фоне. Исторические другие генерации не нужны для продолжения. |
| Отдельный стол | art/sources/kitchen/serving_table.png | ServingTableVisual. Позицию/масштаб согласовывать с блокером и Surface. |
| Банка гречки | art/sources/buckwheat-jar/original.png | Прислана владельцем; источник/права вне чата не установлены. В игру импортирована с обрезкой прозрачных внешних полей. |
| Кастрюля, 10 состояний | game/images/potvisual-* | Временная аккуратная графика текущего прототипа; отдельный редактируемый исходник не найден, игровые PNG сохранены без изменений. |
| Исходный концепт и его изображения | docs/source/concept-2026-10-13.docx | Источник требований/референсов. Не считать изображения автоматически разрешёнными для публичного игрового использования. |

Архивные анимации внутри Grandma сохраняются для отката; runtime не использует старые walk_W/E/SW/SE при движении. В STATUS/NOTICE не объявлена проверка всех внешних прав. Не удалять архивные кадры в задаче упаковки без согласования — они зарегистрированы в объекте.

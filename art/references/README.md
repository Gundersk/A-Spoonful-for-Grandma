# Допустимые референсы владельца

Переданы владельцем01.11.2026 в Референсы.zip; **не дизайнером**, не финальный выбор UI, не внедрённые ассеты. Сохранены все11исходных файлов без изменения байтов:10изображений и TXT22элементов. Имена нормализованы для навигации; полное соответствие исходным именам/пути архива и SHA256 — [manifest.json](manifest.json). ZIP повторно не хранится.

- [Книга: макет, атласы, нумерация22, состояния](recipe-book/README.md).

Отличать art/references (ориентиры владельца), art/proposals (новые обсуждаемые предложения), art/sources (исходники принятых игровых материалов), game/images (импортированные кадры). Референсы не включаются в .c3p и не заменяют игровые PNG без отдельной задачи. Изображённые цифры/замки/инструменты/ассортимент не вводят правил сами по себе; текстовый дизайн имеет приоритет. Права/точные модели конкретных файлов дополнительно не установлены, источник подачи — владелец.

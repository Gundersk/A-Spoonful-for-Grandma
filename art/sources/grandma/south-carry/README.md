# Переноска вниз

Новые цельные кадры для carry_walk_S_generated. Built-in imagegen; источник sheet.png. Референсы: game/images/grandma-walk_s-000.png, grandma-walk_s-001.png (движение ног), grandma-carry_idle_s-000.png (образ и руки). PROMPT.md содержит запрос. Порядок листа: верхний левый, верхний правый, нижний левый, нижний правый. Все четыре кадра осмотрены отдельно и рядом в frames.png. Фазы: левая впереди, сближение, правая впереди, переход к следующему шагу.

Использована только нарезка полной фигуры по 2×2, один общий коэффициент масштаба 240/530 и выравнивание вершины по y65, центр x128. Кадр256×320, Origin(.5,.95), loop=true, 8fps. Части тела не вырезались/не переставлялись/не дорисовывались. Старые файлы остаются в проекте. Это визуальный просмотр кадров, не подтверждённый Preview Construct.

# Переноска NW и зеркало NE

Built-in imagegen. Один новый цельный лист4кадра, сетка2×2, порядок слева направо/сверху вниз. Первый вариант отклонён из-за почти неизменной ведущей ноги; в выбранном вынос правой обуви внизу справа чередуется с выносом левой внизу слева, между ними две фазы сближения. Руки подняты, предмета нет, фон прозрачный.

Выполнена только целокадровая нарезка/выравнивание и единый масштаб240/526 на холст256×320; вершина фигуры y65, центрx128, Origin(.5,.95). Части тела не редактировались. Все кадры просмотрены в sheet.png и frames.png. Импорт через исправленный MCP в carry_walk_NW_generated,4кадра/8fps/loop. Для NE используется та же анимация с зеркалированием движком. Старые carry_walk_NW/NE, walk_NW/NE, carry_idle_NW/NE сохранены. Визуальная проверка кадров не заменяет Preview.

# Отобранные исходники

Сохранены актуальные листы бабушки, кухня/стол и исходная банка. Для остальных кадров исходным материалом пока служат зарегистрированные PNG в game/images. Это не потерянные runtime-ресурсы. Каталоги и ограничения описаны в docs/ASSET_SOURCES.md и docs/ASSETS.md. Новые утверждённые исходники добавлять сюда с осмысленными именами и источником; предложения сначала art/proposals или Issue.

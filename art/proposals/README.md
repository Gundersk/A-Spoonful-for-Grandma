# Предложения графики

Основная карточка — в YouGile. Можно прикрепить PNG там или, для технического обсуждения, к связанному Issue «Ассет или замена графики», не устанавливая Git. Для комплекта в репозитории создайте папку `<предмет>-<вариант>` в своей art-ветке, добавьте файлы и README по шаблону ниже, откройте PR. Подробности: ../../docs/DESIGNER.md.

## Шаблон README предложения

- Название / автор / дата:
- Статус: Предложено (затем На обсуждении / Утверждено / Внедрено).
- Карточка YouGile(URL/ID), связанный технический Issue/PR:
- Что заменяет: точное имя объекта/анимации либо новый предмет.
- Файлы: игровой PNG, превью, исходник.
- Размеры / сетка / количество кадров / Origin:
- Состояния и порядок кадров:
- Обоснование изменения / что ещё не готово:
- Происхождение / права использования:
- После внедрения: commit, результат проверки в Construct, ссылка на ASSETS.

Файлы отсюда не входят в игру/сдаваемый пакет до отдельного импорта и регистрации.
